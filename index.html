Interpretation and limitations

  • The 0.80 ratio is an optional screening convention, not a universal legal test.
  • A ratio below 0.80 is a signal for further investigation, not proof of discrimination.
  • Groups with fewer than 30 applicants are flagged; small samples make rates unstable.
  • These calculations do not account for job relevance, data quality, confounding factors or the full selection process.
  • Qualified-applicant comparisons are descriptive and do not establish that qualification criteria are fair.
  • This tool does not establish causation, fairness or legal compliance.

How to Prepare Your Data

What should your file contain?

Required columns

Your first row must contain these exact column names:

candidate_id, group, qualified, selected

What each column means:

  • candidate_id: A unique ID for each applicant, e.g. C001.
  • group: The group being compared, e.g. Group_A or Group_B.
  • qualified: Enter 1 if qualified, or 0 if not qualified.
  • selected: Enter 1 if selected, or 0 if not selected.

Example of correctly formatted data

Supported file formats

  • CSV (.csv): Save your data as a comma-separated CSV file.
  • Text (.txt): Use a delimited text file with the column names in the first row.
  • Excel (.xlsx): Put the data in the first worksheet, with column names in the first row.
  • PDF (.pdf): Experimental support. The PDF must contain extractable text in a delimited table format. Scanned PDFs and complex visual tables may not work.

Important: Use unique candidate IDs, enter only 1 or 0 for qualified and selected, and do not select an unqualified candidate. Maximum file size: 10 MB. Old Excel .xls files are not supported.

Independent learning prototype. Sample data is synthetic. Do not use this tool alone to make real recruitment decisions.
